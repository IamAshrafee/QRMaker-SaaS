# Quick Start: Admin Account Creator

## 🚀 Run This Command

```bash
npm run admin:create
```

## What It Does

Creates an admin account with:
- ✅ **Full admin access** to `/admin` dashboard
- ✅ **Pro plan** by default
- ✅ **Secure password hashing** (bcrypt)
- ✅ **Interactive prompts** for easy setup

## Password Requirements

- 8+ characters
- At least 1 uppercase letter
- At least 1 lowercase letter
- At least 1 number
